Seasonal battery reserve on a Fronius GEN24 with Home Assistant

#home-assistant #fronius #solar

This article describes a Home Assistant automation that sets the minimum battery reserve of a Fronius GEN24 inverter by month. The method uses local Modbus TCP and the core Fronius integration. It requires neither a cloud service nor a custom integration.

Test system

Schedule

Procedure

  1. In the inverter UI under Communication > Modbus, switch on the Modbus TCP server and "Inverter control via Modbus". Without the second switch, Home Assistant creates no control entities.
  2. Restart Home Assistant. Reloading the integration was not sufficient on the test system.
  3. Open the inverter device in Home Assistant. The number entity "Battery minimum reserve" is listed under Configuration, with a range of 0 to 100% and a step of 1.
  4. Add the automation (Listing 1).

The automation behaves as follows:

  • With the grid available, the reserve of the current month is set.
  • With the backup mode on, the reserve is set to 7%.
  • A missed day is corrected by the next run.

Verification

  • The first read of the entity returned 7.0, identical to the value set in the inverter UI.
  • The automation is in operation. The reserve was at 50% as of November 14, 2026.

Documented behavior

The following behavior is documented but was not tested on the test system.

  • With the grid available, the battery does not discharge below the reserve (Fronius).
  • With the State of Charge (SOC) below the reserve, the battery recharges from the grid. The reported rate is 0.5 kW (fronius_modbus). Therefore, every step up of the schedule can trigger that recharge.
  • In backup mode, the reserve and manually set SOC limits do not apply. The battery discharges to the minimum preset by its manufacturer (Fronius). Thus, the backup trigger in the automation is a safeguard, not a requirement.
  • The value stays on the inverter while Home Assistant is down and after the integration is removed (Home Assistant).

Open questions

  • It is open which field of the inverter UI shows the written value: "SoC Minimum" or "Reserve Capacity".
  • A backup test with the SOC below the reserve is pending.
