Shelly Camera as baby monitor without cloud

#shelly #home-assistant #self-hosting

This article describes how a Shelly Camera is operated without the Shelly cloud for baby monitoring. A cloud-free Shelly camera app does not exist. However, the camera runs locally through its Web UI, the Real Time Streaming Protocol (RTSP), WebRTC, a Network File System (NFS) share, and MQTT.

Apps

Local interfaces

The following functions remain cloud-only: (1) object recognition for people, pets, and vehicles, (2) cloud storage, and (3) offline notifications. Shelly Cloud Premium costs 3.99 € per month for one camera. Camera Storage costs 6.99 € per month for up to 3 cameras, 10.99 € for up to 6, and 14.99 € for up to 10 (product page).

Options

Motion events reach other systems over MQTT or webhooks. Therefore, automations require neither the cloud nor Home Assistant.

Procedure

After the following seven steps in the Web UI, the stream is available to local software.

  1. Open the Web UI at the IP address of the camera. Assign the camera a fixed DHCP lease.
  2. Set a password in the Authentication tab, as RTSP carries video and audio in clear text.
  3. Enable RTSP. The main stream serves recording. The substream serves detection and previews.
  4. Configure the storage: insert a FAT32 microSD card or configure the NFS share.
  5. Disable the cloud connection. The cloud icon in the header turns gray.
  6. Keep the RTSP port inside the LAN. Do not forward the port. Use a VPN for remote access.
  7. Point go2rtc or the NVR at the RTSP URL shown in the Web UI.

Home Assistant

  • The Shelly integration delivers the motion state, not video. The camera is discovered, and its motion sensor appears.
  • The stream must be added manually as a generic camera with the RTSP URL (techtest.org).
  • A camera entity without a picture indicates this gap, not a broken installation.
  • go2rtc standalone or an NVR removes Home Assistant from the video path entirely.
