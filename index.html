01 / Work

What I do

  • Embedded Linux and firmware

    Board bring-up, kernel and userspace configuration, daemons that survive reboots and bad power. ARM single-board computers, SPI and I2C peripherals, cross-compilation, systemd.

    C · Rust · Zig · ArchLinuxARM · systemd

  • Mesh and radio networking

    Meshtastic and LoRa deployments for communities and sites with no infrastructure to lean on. Node configuration, gateways, telemetry pipelines, and the dashboards that make a mesh legible.

    LoRa · Meshtastic · SX126x · protobuf · SQLite

  • Tooling and infrastructure

    Small, durable services instead of platforms: HTTP APIs, ingestion pipelines, self-hosted deployments with Docker, and the scripts that hold them together. Documentation included.

    Rust · C++ · Docker · SQLite · Linux

PotatoMesh, a white-label dashboard for Meshtastic community meshes: map, messages and node table, fed by a serial ingestor. Running for the Berlin mesh at potatomesh.net, source on GitHub.
