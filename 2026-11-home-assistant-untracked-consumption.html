Home Assistant: naming untracked consumption per upstream device

#home-assistant #energy

This article describes how the untracked consumption of an upstream device receives its own name in the Home Assistant energy dashboard. Home Assistant provides no per-device name for this remainder. Therefore, the remainder is computed by a separate sensor and added as a device under the parent.

Problem

  • The energy flow cards draw one gray node "Untracked consumption" (German: "Nicht erfasster Verbrauch") under every upstream device, plus one at home level.
  • All nodes carry the same label and the same gray. The chart does not show which parent a node belongs to.
  • The individual device graphs label the same remainder <Device> (untracked).

Finding

  • The label is a fixed frontend string. Home Assistant has no per-device name for it.
  • Two pull requests (PRs), frontend PR #55581 and core PR #190110, proposed an "Untracked consumption name" field. The frontend PR was closed unmerged on November 3, 2026. The core PR is closed as well.
  • The maintainer's answer was to give the remainder its own sensor and to add it as a device under the parent.

Procedure

The example uses a metered plug (Network Hub) that feeds a miner (NerdQAxe), which reports its own power.

  1. Add a template sensor that subtracts the child power from the parent power, floored at zero (Listing 1).
  2. Add an integral sensor that converts W to kWh with a left Riemann sum (Listing 1).
  3. Restart Home Assistant.
  4. Open Settings → Dashboards → Energy → Individual devices → Add device and enter the values of Table 1.

The miner keeps Network Hub as its upstream device.

Verification

  • The gray node under the parent drops to zero. The remainder appears under its own name in all energy cards.
  • The home-level "Untracked consumption" remains.

Limitations

  • There is no backfill. Days before the change stay gray.
  • An unavailable child counts as 0 W. Its load moves to the remainder.
  • The miner reports board-level power, whereas the plug measures at the wall. Therefore, the power supply loss lands in the remainder.
  • The integral and the plug counter differ slightly. A thin gray sliver can remain.

Alternative

The Sankey Chart card from the Home Assistant Community Store (HACS) can be used on a custom dashboard. Its node type remaining_parent_state takes a free name per parent. However, the chart configuration must be maintained by hand.
